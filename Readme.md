ZeroCode Challenge Application

This repository contains my submission for ZeroCode, the national prompt engineering challenge hosted by Techfest, IIT Bombay (Asia's largest science and technology festival).

The entire application was built under a strict 70-minute time limit using zero manual coding. The codebase was generated exclusively through precise, structured prompts using the Gemini Flash model on Google AI Studio.

Challenge Constraints Conquered

This project was built under strict competition rules designed to test prompt architecture and logic structuring:

100% Vanilla Stack: Absolutely no external libraries, frameworks, or CDNs (No React, Tailwind, Bootstrap, or jQuery).

Zero External Assets: All UI elements and icons are built using inline SVGs and native CSS.

Strict Prompt Limit: Built using a highly restricted number of prompts to avoid point penalties, requiring "spec-first" meta-prompting and rigorous context management.

No Manual Edits: Every line of code, bug fix, and responsive adjustment was executed entirely via AI prompting.

Tech Stack

HTML5: Semantic structure and accessibility.

CSS3: Custom variables (:root), Grid/Flexbox layouts, glassmorphism UI, and purely native animations/transitions.

Vanilla JavaScript (ES6+): Encapsulated logic (IIFE), strict state management, and real-time DOM updates with rigorous edge-case sanitization.

Prompt Engineering Approach

To achieve a production-grade application within the prompt limit, I utilized a structured prompt architecture:

Master Scaffolding Prompt: Defined semantic HTML IDs, CSS design tokens, and JS state management upfront to prevent AI UI hallucinations.

Logic Hardening Prompt: Focused solely on edge-case testing, input sanitization, and mathematical accuracy.

UI/UX Polish Prompt: Applied mobile responsiveness, micro-interactions, and visual layout tweaks.
